# つぎは Metro — 픽셀아트 스타일 가이드

기준 그림: `reference_shinjuku_evening.png` (오너가 2026-11-17에 지정한 "원하는 느낌")

## 기준 그림에서 배운 것

| 요소 | 기준 그림 | 지금 앱(코드로 그린 것) |
|---|---|---|
| 시점 | 원근(소실점 1개). 전철이 정면에서 다가옴 | 옆에서 본 평면 |
| 해상도 | 약 380×250 아트 픽셀, 1픽셀 ≈ 4px | 약 160×84 |
| 외곽선 | 검은 외곽선이 거의 없음. 색 차이로 형태를 구분 | 검은 외곽선 |
| 명암 | 그림자는 보라·남색 쪽, 밝은 곳은 주황·노랑 쪽(색상 이동) | 같은 색을 어둡게만 함 |
| 빛 | 한 방향 빛(노을)이 전체를 물들임. 차체·기둥 가장자리에 반사광 | 빛 방향 없음 |
| 공기원근 | 먼 빌딩은 하늘색에 섞여 흐리고, 가까운 것만 선명하고 디테일이 많음 | 레이어 색만 다름 |
| 생활감 | 사람, 점자블록, 승강장 번호, 형광등, 가선주 | 없음 |
| 디더링 | 거의 없음. 색 덩어리(클러스터)로 표현 | 없음(정리 후) |

결론: 이 수준은 손으로 그린(또는 이미지 생성) **일러스트**이며, 코드로 점을 찍는 방식으로는 도달할 수 없다.
→ 풍경은 **PNG 일러스트 에셋**으로, UI(카드·버튼·글씨)는 지금처럼 **깔끔하게** 둔다.
화려한 그림 + 차분한 UI의 대비가 촌스럽지 않게 보이는 핵심.

## 꼭 지킬 것 (상업 앱)

- **실제 로고 금지:** JR 마크, 도쿄메트로 마크, 회사 고유 역명판 디자인(JR 역명판 양식 등)을 쓰지 않는다.
- **실제 차량 그대로 금지:** E235 같은 실제 차량을 그대로 그리면 철도회사의 상품화 허락이 필요할 수 있다. 노선색 띠는 쓰되 앞모습은 **오리지널 디자인**으로 한다.
- 역명판은 앱 고유 양식(흰 판, 노선색 선, 일·영 표기)으로 하되 JR 양식과 다르게 한다.
- 건물 실루엣(도청 등)은 일본 저작권법 46조상 문제없음. 그래도 간판 글자나 상표는 넣지 않는다.

## 에셋 계획

1. **のりば 헤더 일러스트** (가장 먼저)
   - 가로:세로 = 2:1, 원본 384×192 아트 픽셀(PNG, 확대하지 않은 원본).
   - 낮 / 저녁 / 밤 3장. 비·눈·흐림은 코드로 위에 덧그린다(빗줄기, 회색 톤).
   - 전철은 배경과 **별도 레이어**(투명 PNG)로 만든다. 그래야 MY룸에서 장착한 전철로 바꿔 끼울 수 있다.
2. **전철 정면 스프라이트**: 오리지널 디자인, 노선색 부분은 지정한 색 1개만 쓴다(코드로 색 교체).
3. 진행 막대, 잠금화면용 작은 전철(옆모습)은 지금처럼 작은 스프라이트를 유지한다.
